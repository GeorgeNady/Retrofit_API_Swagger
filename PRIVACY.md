# Privacy Policy for Retrofit API Swagger

**Last Updated:** September 1, 2026

This Privacy Policy describes how **Retrofit API Swagger** ("the Plugin", "we", "us", or "our"), an extension for IntelliJ IDEA and Android Studio developed by **George Nady**, handles data when you install and use the Plugin.

---

## 1. Data Collection and Usage

**Retrofit API Swagger** operates entirely locally within your Integrated Development Environment (IDE).

- **No Personal Data Collection:** We do not collect, capture, store, or transmit any personally identifiable information (PII), telemetry, usage statistics, or user behavior data.
- **No Code Transmission:** All source code analysis, AST parsing, and network endpoint visualizations are performed locally on your machine. Your source code, API keys, endpoints, and project structure are never transmitted to external servers or third parties.
- **Local Configuration Storage:** Plugin settings (such as UI preferences and configuration defaults) are stored locally on your device via standard JetBrains IDE settings mechanisms (`SwaggerSettingsService`).

---

## 2. Network Activity

- **Local IDE Execution:** The Plugin does not connect to any remote server managed by the developer or any third-party analytics provider.
- **Developer-Initiated Endpoint Testing:** If you choose to use the interactive testing ("Try It Out") feature within the Plugin, HTTP requests are issued directly from your local machine to the target server specified in your own project code or mock configuration. No data is routed through or inspected by intermediaries.

---

## 3. Third-Party Services and Analytics

- The Plugin does **not** include any third-party tracking libraries, analytics frameworks, advertising SDKs, or external logging services.

---

## 4. Changes to This Privacy Policy

We may update this Privacy Policy from time to time to reflect changes in functionality or legal requirements. Updates will be published in this repository.
